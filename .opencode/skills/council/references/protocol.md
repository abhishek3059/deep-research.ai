# Council Protocol

## Panel Selection
1. If user specifies --members, use those
2. Else if --triad, resolve that triad
3. Else if --profile, use default triad
4. Else inspect for keyword triad
5. Else use classic + architecture

## Rounds
- Round 1: Independent Analysis (blind, parallel)
- Round 2: Cross-Examination (sequential)
- Round 3: Final Position (short stance)

## Enforcement Rules
- No recursive questioning loops
- Require real disagreement before consensus
- If consensus too early, run counterfactual pass
